# SPIRIT Browser delivery plan

Scope: browser-only control of existing Chrome tabs on Windows 11. Desktop mode removed.

1. Implement an MV3 chrome.debugger extension and authenticated local bridge.
2. Add consent-based direct CDP fallback for an existing session.
3. Provide AX refs, background screenshots, isolated cursor, input, forms and files.
4. Publish tab resources and file references for client @ pickers.
5. Validate local fixture pages, protocol, security boundaries and ordinary user Chrome.
6. Update agy skill, custom repository artwork, documentation and release packages.

The concrete architecture and API restrictions are documented in ../../architecture.md.
The actual validation record and diagnosed legacy failures are in ../../validation.md.
